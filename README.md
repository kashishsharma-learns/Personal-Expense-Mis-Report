# Personal Expense Tracker & MIS Report

A personal practice project built to strengthen data entry, data cleaning, and MIS reporting skills using Excel/Google Sheets — created as part of preparing for Data Entry Operator / MIS Executive roles.

## Overview

This project simulates a real-world MIS reporting workflow: starting from raw transactional data, cleaning it, applying lookup logic, and summarizing it into a clear, decision-ready report.

## What I Did

- **Data Entry**: Entered and organized 80+ expense transactions with fields — Date, Category, Description, Amount, and Payment Mode
- **Data Cleaning**: Removed duplicate entries, standardized category names and date formats, and validated data consistency
- **VLOOKUP**: Mapped each expense category against a monthly budget limit reference table to compare actual vs. budgeted spend
- **Pivot Tables**: Summarized total spend by category and by month
- **Data Visualization**: Created column and pie charts to visualize spending trends

## Key Insight

Rent was the highest spending category overall, followed by Groceries and Eating Out.

## Tools Used

- Google Sheets
- Formulas: VLOOKUP, SUM
- Pivot Tables
- Charts (Column, Pie)
